# Lodestar 1.0.0

*Released 2026-10-15*

Lodestar is a free, open-source sideloader for iPhone, iPad and Apple TV 4K, written
in native Rust for the Mac. Sign an app with your own Apple ID, install it, and
refresh it before the week is up. No paywall, no tracking, no Python or Qt.

<img src="../images/install-dark.jpg" alt="Lodestar's Install page" width="760">

## Highlights

- **One native binary.** 21 MB, `arm64`, no Rosetta. (Sideloadly 0.70 for Mac is a
  285 MB `x86_64` app.)
- **Apple TV 4K as a first-class target.** Installs to an Apple TV that is already
  paired with your Mac, and can pair a new one with the on-screen PIN and install over
  an encrypted tunnel.
- **Everything is free.** Display name, bundle ID, device-restriction removal, file
  sharing, extension stripping, refresh-all. There is no paid tier.
- **My Apps** shows what you've installed, when each signature expires, and whether
  the device is online. Refresh one app or all of them.
- **Handles Apple's certificate limit** for you instead of stopping with an error.
- **Designed, not defaulted.** Light and dark, IBM Plex type, and animation that
  explains state and switches off with *Reduce Motion*.
- **Private by construction.** No telemetry or update check. Passwords and keys live
  in the Keychain. You can run your own anisette server.

## Install

Download `Lodestar-1.0.0-arm64.zip`, move `Lodestar.app` to Applications, and
right-click › **Open** the first time (builds aren't notarized). Or build it:

```bash
git clone https://github.com/asroya/lodestar.git && cd lodestar && ./packaging/bundle.sh
```

The [user guide](../GUIDE.md) walks through signing in, connecting a device and
installing an app.

## Limits you should know about

Apple's free accounts allow **3 apps per device, 7-day signatures and 10 new App IDs
per week.** Those are Apple's rules; Lodestar just makes them easy to live with.

Lodestar 1.0 does **not** have: background auto-refresh, JIT enabling, tweak or dylib
injection, a Windows or Linux build, or paid-account features such as custom
entitlements.

## Bugs fixed on the way to 1.0

Found by real use and by writing the tests:

- Apple TV installs returned 404 (tvOS requests used a path Apple's service lacks).
- Installs stopped at Apple's certificate limit (the wrong certificate was chosen).
- A mistyped password was saved, then retried silently on every launch.
- An older settings file would have reset everything, including the saved Apple ID.
- A failed install left the unpacked app behind in the temp folder.
- A background crash at launch when *Remember me* was on.
- A control on the Devices page ("Add by IP") that did nothing was removed.

## Privacy and licensing in one paragraph

Lodestar talks to Apple, to an anisette server (a community one by default; you can
self-host), and to your own devices. Your Apple ID password goes only to Apple, over
SRP. The code is MIT licensed. One dependency, `apple-codesign-quick`, is
LGPL-2.1-or-later, used unmodified and replaceable; see
[THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).
